# Python AI Akinator

An interactive 20-Questions AI Guessing Game built with Python, Tkinter GUI, and Decision Tree Expert System logic.

## 🎮 Features
- **Desktop GUI**: Clean graphical interface built with Tkinter.
- **Expert Decision Tree**: Dynamic question traversal to guess characters.
- **Score & History Tracking**: Records gameplay rounds and user outcomes.

## 🚀 Running the Game
```bash
python akinator_game.py
```
